# Telvax

Telvax is a statically typed, compiled language for data, ML pipelines and AI serving. It is an early alpha.

* [telvax/telvax](https://github.com/telvax/telvax): the compiler, runtime, standard library, CLI and docs.
* [telvax/rfcs](https://github.com/telvax/rfcs): proposals for changes to the language and the tools.

Questions and ideas go to [Discussions](https://github.com/telvax/telvax/discussions). Security problems are reported privately; see [SECURITY.md](https://github.com/telvax/.github/blob/main/SECURITY.md).
